# 【呵呵】AI工作室

在 Windows 本机打开 3D 办公室，写下任务目标。Carbon 规划，Astra 选择员工并分工，任务台保留每一步的方案、执行记录和验收结果。

## 克隆与二次开发

获得私有仓库访问权限后即可克隆源码。只想先看办公室，装好 Python 3.11 或更新版本后就可以启动网页，在界面切到「演示」查看模拟状态。

```powershell
git clone https://github.com/Slash214/ai-office.git
cd ai-office
python -B server.py
```

启动后打开 [本机办公室](http://127.0.0.1:8765/)，按 Ctrl+C 可停止前台服务。需要真实派单时，在自己的电脑上安装模型 CLI、登录自己的账号，并核对可用型号。[员工接入指南](INTEGRATION.md)

- **改 3D 办公室和界面**。从 `public/scene.js`、`public/crew-design.js`、`public/rooms.js` 和 `public/studio.css` 入手。
- **改派单和验收流程**。查看 `workflow.py`、`project_coder.py`、`releases.py` 和 `public/tasks.js`。
- **改 Windows 桌面和托盘**。修改 `native/` 下的 C# 文件，再用下面的构建命令生成 EXE。

安装 Node.js 后，可以运行回归测试。允许推送分支的同事可建分支并提 Pull Request。

```powershell
python -B -m unittest discover -q
node --test test_navigation.mjs
```

各自的任务、令牌和个人 Dot 连接保存在本机 `.office-data/`。该目录、本机工具、运行截图和生成的 EXE 都在 Git 忽略规则里。自定义连接器配置可另存为 `*.local.json`，用 `office_connector.py --config` 指定。本机 API 密钥请用环境变量。

## 打开工作室

在 64 位 Windows 上克隆后，运行以下命令构建 **AI工作室.exe**。首次构建会从 NuGet 下载并校验固定版本的 WebView2 SDK，然后生成 `native/webview2/` 运行文件。桌面窗口需要本机安装 Microsoft Edge WebView2 Runtime。

```powershell
powershell -NoProfile -ExecutionPolicy RemoteSigned -File .\native\Build.ps1
```

双击 **AI工作室.exe** 打开三维办公室，点击「分配任务」即可派单。重复双击会唤回同一个窗口。请将 EXE 留在工作室文件夹，方便它加载页面和本地服务。

点击窗口顶部「开启桌面壁纸」，主显示器图标后会显示完整 3D 办公室、人物动作和闲聊。开启壁纸后关闭主窗口，壁纸继续运行。双击托盘的工作室图标可重新派单；右键可关闭壁纸或退出桌面程序。也可执行 `AI工作室.exe --wallpaper`。需要重编译 EXE 时，运行 `native/Build.ps1`。

蓝色 `>_` 桌宠首次出现在主屏幕右下角。待机时轻轻呼吸，收到 Codex 的编写状态时换成敲键盘的动作。按住小人可以拖动，双击打开工作室派单。右键小人可隐藏桌宠，右键托盘图标可重新显示。工作室会记住桌宠的位置和显示设置。

桌宠平时只显示小人。移入后出现白色工具条，点铅笔输入任务并按 Enter 派发，按 Esc 收起并保留草稿。另一个按钮打开待验收工单或工作室。桌宠和壁纸约每三秒读取本机状态。可见壁纸按屏幕原生分辨率绘制，人物动画以每秒 24 帧为目标，待命时也保持同一帧率。壁纸墙上的两块看板显示工单数量和最近步骤，接力光点对应刚发生的交接。

要求交付文本时，可以在工作室勾选「将最终正文保存为 Windows 桌面 TXT」，也可以直接派单「在桌面创建一个 TXT，写……」。文本定稿后由本机服务以当前用户的权限写入桌面，任务台显示文件名。同名文件内容不同时自动另存。工单详情中的「运行日志与错误记录」可展开查看技术细节。

用 `AI工作室.exe --wallpaper` 单独启动壁纸时，只创建一个 3D 窗口。双击桌宠或托盘图标才加载派单窗口。把空闲的派单窗口最小化或收回托盘，约 12 秒后会释放这个窗口的渲染资源。有草稿或打开的对话框时，窗口会挂起以保留内容。Python 后台继续处理已经派发的任务。

也可双击 **打开工作室.pyw**，用默认浏览器打开 [本机办公室](http://127.0.0.1:8765/)。在终端中可运行以下命令。

```powershell
python ".\打开工作室.pyw"
```

关闭浏览器后，后台工作室仍可继续已经授权的任务。Windows 重启后再次双击入口即可恢复任务台。上次关机时正在运行的步骤会提示中断，打开该任务可选择重试或回填结果。

需要查看启动错误时，在工作室文件夹里执行 `python -B server.py`，保留终端并打开上面的本机地址。按 Ctrl+C 可以停止这个前台服务。更新代码后重开后台服务时，先等正在执行的步骤结束，再在任务管理器的「详细信息」中核对「命令行」指向本目录 `server.py` 的 Python 进程，结束该进程后重新双击入口。

## 总裁派单与团队交接

1. 在**实时**模式点击「分配任务」，写下目标和交付物，点「派发并开始」。你可以直接写「优化办公室 UI，让手机上更容易看清员工在做什么」。
2. Carbon 先规划，Astra 根据目标、员工能力和连接状态决定分工。办公室代码开发由本机 Codex 执行，文本或资料类工作可交给 Gemini 成员，接入的协作插槽也可参与。规划、复核和执行会自动接力。
3. 已派发的任务使用相应模型账号的额度，忙时自动排队。点「停止任务」可撤销排队、终止本机工作室启动的模型及测试进程，或关闭等待交接的工单。个人 Dot 和同事电脑已开始的工作由各自设备控制，停止后工作室会拒收它们的结果。
4. Codex 验证通过后会留下候选版。点「预览候选版」可查看界面和文件差异，或提交「打回修改」继续返工。点「验收并发布」才更新正式源码。之后可点「一键回退」恢复本次涉及的文件。如果后来有人又修改了同一文件，工单会显示冲突，避免覆盖新改动。
5. Windows 托盘在任务待验收、需要人工交接或失败时提醒。点击提醒打开对应工单。右键托盘图标的「打开待办提醒」也可以访问这些工单。
6. 使用 **Dot** 时，在成员详情或待交付步骤点「连接我的 Dot」，复制入驻指令并打开个人会话。Dot 可以在已获授权并且在线的电脑上读取自己的工单、把结果写回。每次指令只处理一项；需要继续开会时在该会话里交流。电脑离线时仍可把实际答复人工转交到任务台。

## 同事的自定义插槽

如果同事只是想加入你运行的办公室，从页面下载「同事连接包」，按接入指南连接即可。想运行自己的办公室或制作改版时，再克隆仓库。

在团队成员面板点击「协作插槽」，为同事的本地 Agent 或模型 API 创建一个名字，将该席位令牌私下交给他。「同事如何接入」可下载包含连接器、两种配置示例、Windows 入口和说明的 ZIP。办公室最多同时容纳 12 个自定义执行席位。Astra 可将任务分给在线的协作员工，你也可以在目标里点名。

同事的电脑向专用端口领取自己的任务，只需本机 Python，无需安装完整工作室。连接器支持固定命令行程序和兼容 Chat Completions 的模型。模型密钥在同事电脑上的环境变量里配置。跨机可使用已有 SSH 通道转发办公室的协作端口（默认 8766，可用 `OFFICE_WORKER_PORT` 修改）。办公室控制台默认端口 8765 仅供本机使用。[同事接入指南](connectors/接入指南.md)

创建过插槽时，3D 全景会在前侧增加相应的协作工位。桌面展示使用编号席位，总裁面板可查看每个编号对应的私有名称。

演示模式展示模拟动态。只看办公室、打开任务台和查看连接状态不会启动模型推理。型号绑定、本机 CLI 登录、从终端上报和手动接入方法见 [员工接入指南](INTEGRATION.md)。

## 观察办公室

真实工单进入规划后，呵呵大王和桌宠会显示当前派单阶段。Carbon 规划、Astra 分工、执行成员接手时，角色动作和状态随之更新。尚未分到工作的成员会回工位等待。点桌宠头上的任务提示可直接打开对应工单，查看受阻步骤或验收结果。

要试走一遍流程，可以派发「在桌面创建一个可以离线打开的 HTML 展示页」。团队交回完整单文件源码后，宿主将其保存到当前 Windows 用户的桌面并回读校验。任务台显示实际文件名，打开文件看效果后再验收。同名且内容不同的文件会自动编号。

若 Carbon 报告 Antigravity 会话数据库初始化冲突，工作室会在确认会话尚未建立时最多尝试三次启动。仍然受阻时，打开原工单点击「重试当前步骤」即可接着运行。日志中的账号信息和任务原文保留在本机。

可以拖动场景旋转，使用全景、工位、会议区、休闲区切换机位。点击成员名字，再选「看工位屏幕」，可以从近处观察该员工的电脑、坐姿和操作。点击近景中的工位名称可回到全景。

工位屏显示的是状态和任务类别。员工喝咖啡、玩街机和头顶的短对白是本地编写的日常演绎。点击「场景闲聊」可收起对白。真实任务进度和模型产出在总裁任务台查看。

## 端口与本地数据

双击入口始终监听本机 `127.0.0.1`，默认端口为 `8765`。要使用其他端口，可在同一 PowerShell 中设置 `$env:OFFICE_PORT = "8876"` 再运行入口。终端上报工具连接自定义端口时，也要设置 `$env:OFFICE_URL = "http://127.0.0.1:8876"`。

任务正文和工作成果保存在 `.office-data/tasks/`，工位上报状态保存在 `.office-data/state.json`，上报密钥默认在 `.office-data/report-token`。备份工作室时请妥善保存这份私人数据。本机模型 CLI 使用各自的账号登录；从任务台发起推理时，当前简报和该步骤所需的上游结果会交给相应模型服务商。读取工位状态的接口仅返回成员、状态、任务类别、协作者及更新时间。
