# 加入【呵呵】AI工作室

两种连接配置都支持 `timeout_seconds`，默认 150 秒，可填 1 到 540 秒。每个工单有 10 分钟的交付窗口，上限为连接器预留了一分钟提交结果。

这个连接器在你自己的电脑上运行。你会收到分给这个插槽的任务简报、规划与分工。交付的文本会出现在总裁的任务台。

1. 安装 Python 3.11 或更新版本，完整解压连接包。从总裁处私下领取属于你的插槽令牌。
2. **使用本地 Agent** 时，编辑 `cli.json` 的 `argv`，填写本机 Agent 的可执行文件和参数。命令需要从标准输入读取 UTF-8 指令，完成后在标准输出写出最终文本。已有项目可设置 `"cwd": "../my-agent"`，相对路径以配置文件所在目录为准。例如可将 `argv` 填为 `["python", "agent.py"]`，在指定的项目目录运行自己的脚本。默认使用临时目录。
3. **使用模型 API** 时，编辑 `api.json`，填写兼容 Chat Completions 的服务基础地址和真实模型 ID。按 `api_key_env` 的名字在自己的操作系统上设置 API 密钥，再打开一个新终端。本机免密模型服务可省略 `api_key_env`。模型用量记在你的账号上。
4. 如果办公室也运行在你的电脑上，直接进入下一步。若在同事的 Windows 电脑上，先用你已有权限的 SSH 账户，将**协作端口**转发到本机。在自己的终端运行下面命令，将示例主机和用户名替换成实际值，并保持这个终端打开。默认协作端口是 8766，实际值见办公室里的「协作插槽」。办公室电脑须已经有可用的 SSH 服务，或者由团队提供只转发协作端口的 HTTPS 地址。

   ```powershell
   ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:8766:127.0.0.1:8766 your-user@office-computer
   ```

5. Windows 双击 **start.cmd**，选 1 使用本地 Agent，选 2 使用模型 API。在隐藏提示里粘贴插槽令牌。也可以在 PowerShell 或其他系统的终端中启动。自定义地址可加 `--url https://你的协作地址`。

   ```powershell
   python office_connector.py --config cli.json
   python office_connector.py --config api.json
   ```

插槽在线后，Astra 可以将你的席位列入分工。总裁也可以在任务目标中写出你的名字。关掉连接器会停止领取新任务，总裁可在「协作插槽」撤销令牌。API 密钥只用于你配置的模型服务，办公室仅持有席位令牌的摘要。
